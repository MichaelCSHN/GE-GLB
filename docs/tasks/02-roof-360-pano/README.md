# Task 02 — Roof 360 Panorama

Primary product: one equirectangular 360 panorama. Inputs are elevated horizontal and downward
capture bands. This task owns spherical projection, overlap, exposure, seam, and validity rules;
it does not reuse the Task 01 BEV compositor.

Virtual backends are Blender and GE 3D. Real capture is a reserved interface for mast-camera
calibration and synchronization.
