# Active 3D Camouflage — Problem Formalization & Technical Approach

> 本文档形式化描述"上半球空间多视角主动三维伪装"问题，阐明 GE-GLB 项目三任务的
> 上游定位，并给出 CTO 的技术路径建议。作为项目的长期背景资料，不随 sprint 计划变动。

---

## 1. Problem Statement（问题形式化）

### 1.1 定义

令 $\mathcal{T}$ 为一个三维目标（如车辆），其表面流形为 $\mathcal{M} \subset \mathbb{R}^3$。
目标周围存在一个背景环境 $\mathcal{E}$，定义在半球观察空间 $\mathcal{V}$ 上：

$$\mathcal{V} = \{ v \in \mathbb{R}^3 \mid \|v\| = 1,\ v_z \geq 0 \}$$

即所有指向目标的上半球单位方向向量。

**伪装问题**：寻找一个映射 $\mathcal{C}: \mathcal{M} \to \mathcal{A}$，其中 $\mathcal{A}$ 是**可制造伪装系统的设计空间**，使得目标在任意观察视角 $v \in \mathcal{V}$ 下的**可检测性**最小化。

### 1.2 伪装系统的设计空间 $\mathcal{A}$

伪装系统由两个耦合的子系统构成：

#### 子系统 A — 表面迷彩图案（Surface Camouflage Pattern）

一个像素化、可动态改变的表面纹理层，受以下物理约束：

| 约束 | 形式化 | 说明 |
|------|--------|------|
| **各向同性** | $\forall p \in \mathcal{M},\ \forall v_1,v_2 \in \mathcal{V}:\ C(p,v_1) = C(p,v_2)$ | 每个像素在不同视角下显示相同颜色，不能像定向屏那样对方向显示不同图像 |
| **像素尺寸下限** | $\Delta_p \geq \delta_{\min}$（参数化，如 $\delta_{\min}=10\,\text{cm}$） | 正方形像素，边长有物理下限 |
| **有限色域** | $C(p) \in \mathcal{P},\ |\mathcal{P}| \leq N$（参数化，如 $N=256$） | 颜色来自有限调色板 |
| **动态更新** | $\mathcal{C}(t)$ 可根据环境变化重新生成 | 伪装可随时间改变适应新背景 |

迷彩图案可以形式化为一个纹理场：

$$\mathcal{C}_{\text{tex}}: \mathcal{M} \to \mathcal{P}$$

即在目标表面每个点上定义一个颜色。

#### 子系统 B — 局部变形器（Local Deformers）

附加在目标表面的三维几何体，用于破坏目标轮廓、模拟背景结构。

每个变形器 $d_i$ 由其参数向量定义：

$$d_i = (\text{shape}_i,\ \text{pose}_i,\ \text{appearance}_i)$$

其中：

- $\text{shape}_i$：几何形状参数（类型、尺度 $s$、长宽比 $r$、弯曲度 $c$、扭曲度 $\tau$）
- $\text{pose}_i$：位姿参数（附着位置 $\mathbf{u} \in \mathcal{M}$、法向倾角 $(\theta,\phi)$、覆盖面积 $a$）
- $\text{appearance}_i$：外观参数（单色或局部纹理）

整体变形器配置为有限集合：

$$\mathcal{C}_{\text{def}} = \{d_1, d_2, \ldots, d_K\},\quad K\ \text{参数化}$$

### 1.3 目标函数

伪装优化的核心问题为：

$$\min_{\mathcal{C}_{\text{tex}}, \mathcal{C}_{\text{def}}} \ \mathbb{E}_{v \sim \mathcal{V}_{\text{prior}}} \left[ \mathcal{D}\big( \mathcal{R}(\mathcal{T}, \mathcal{C}_{\text{tex}}, \mathcal{C}_{\text{def}}, v),\ \mathcal{R}(\mathcal{E}, v) \big) \right]$$

其中：

- $\mathcal{R}(\cdot, v)$：在视角 $v$ 下的渲染操作
- $\mathcal{D}(\cdot, \cdot)$：可检测性度量（见第 4 节）
- $\mathcal{V}_{\text{prior}}$：观察视角的概率分布（取决于威胁模型）

在实际优化中，$\mathcal{D}$ 被展开为多目标的加权组合：

$$\mathcal{D} = \alpha_1 \mathcal{L}_{\text{visual}} + \alpha_2 \mathcal{L}_{\text{model}} + \alpha_3 \mathcal{L}_{\text{human}} + \alpha_4 \mathcal{L}_{\text{physical}}$$

其中 $\mathcal{L}_{\text{physical}}$ 编码制造约束（间隙、附着强度、材料疲劳等）的惩罚项。

### 1.4 与标准对抗攻击的区别

本问题与标准对抗性攻击（adversarial attack）有本质区别：

| 维度 | 标准对抗攻击 | 本问题 |
|------|------------|--------|
| 视角数量 | 单视角或固定有限视角 | 上半球**连续空间** $\mathcal{V}$ |
| 扰动空间 | 像素级无约束 | **物理约束**：像素尺寸 + 色域 + 各向同性 |
| 攻击对象 | 单一检测模型 | **多模型 + 人类视觉**的联合 |
| 评价标准 | 模型置信度下降 | 背景融合度 + 边界隐蔽性 + 可制造性 |

            │ 仅纹理     │  │ 环境纹理     │   │

         ┌────────┴───────────────┴──────┐   │

| 输入 | GE-GLB 产出 | 在伪装系统中的用途 |
|------|------------|-------------------|
| ① 正下视图像 | Task 01 `underbody.png` + 覆盖诊断 | 地面背景的颜色/纹理统计，低频背景先验 |
| ② 360 全景 | Task 02 `panorama.png` + 有效性掩膜 | 水平环带环境纹理，中频结构匹配 |
| ③ 半球环拍 | Task 03 `viewset.json` + 位姿元数据 | 多视角观测集，3D 重建输入，视角一致性约束 |

**关键设计含意**：GE-GLB 的三个产品必须保持：
1. **精确的位姿元数据** —— 每个 observation 的 `camera_to_world` 变换是后续环境 3D 重建的刚性输入
2. **后端无关性** —— 虚拟（Blender/GE Pro）和实采数据使用相同接口，伪装系统不区分来源
3. **可追踪性** —— 结果清单需记录已知局限（如 flat-ground 假设、缺失覆盖区域），伪装系统需知悉采集的不确定性

## 3. CTO 技术方案

### 3.1 整体框架

我推荐的系统架构分为四个层级：

```text
┌───────────────────────────────────────────────────────────┐
│  Layer 4: 评估层                                           │
│  CV 指标 (纹理/颜色/边缘)  |  检测器集成  |  人眼代理模型   │
└───────────────────────┬───────────────────────────────────┘
                        ↓ 多目标损失
┌───────────────────────────────────────────────────────────┐
│  Layer 3: 优化层                                           │
│  ┌─────────────────────┐  ┌─────────────────────────────┐  │
│  │ 纹理优化器           │  │ 变形器优化器                 │  │
│  │ 可微渲染 → STE量化   │  │ 参数化网格 → 分布优化        │  │
│  │ → 颜色/频率匹配      │  │ → 轮廓打散度量               │  │
│  └──────────┬──────────┘  └──────────────┬──────────────┘  │
│             │                            │                 │
│             └──────┬─────────────────────┘                 │
│                    ↓ 联合渲染                              │
│           ┌──────────────────────────┐                     │
│           │  可微渲染器 (nvdiffrast) │                     │
│           │  + 物理约束前向传播       │                     │
│           └──────────┬───────────────┘                     │
└──────────────────────┼────────────────────────────────────┘
                       ↓
┌───────────────────────────────────────────────────────────┐
│  Layer 2: 场景层                                           │
│  背景 NeRF/3DGS 重建  |  HDRI 环境光照  |  地面纹理场      │
└───────────────────────┬───────────────────────────────────┘
                       ↓
┌───────────────────────────────────────────────────────────┐
│  Layer 1: 采集层 (GE-GLB)                                  │
│  Task 01 车底  |  Task 02 全景  |  Task 03 半球环拍        │
└───────────────────────────────────────────────────────────┘
```

### 3.2 Layer 1: 采集——三种背景观测

见第 2 节。当前项目的全部工作集中在这一层。

### 3.3 Layer 2: 场景层——环境表示

从三种输入重建一个**多模态环境场**：

**背景 NeRF / 3D Gaussian Splatting**（使用输入 ② 和 ③）：
- 重建目标周围环境的近似三维几何
- 输出：视角条件化的背景颜色分布 $\mathcal{B}(x, v)$，即从视角 $v$ 观察空间点 $x$ 看到的颜色

**地面纹理场**（使用输入 ①）：
- 正下视图像提供高分辨率地面纹理
- 与 NeRF 的地面部分融合，填充 NeRF 可能缺失的近地面细节

**环境光照**（从输入 ② 的未遮挡区域估计）：
- 输出 HDRI 环境贴图，用于可微渲染中的物理正确光照

### 3.4 Layer 3: 优化层——联合纹理与变形器生成

#### 3.4.1 迷彩图案生成

采用**可微渲染 + 背景条件纹理场**路线：

```
输入：目标表面 UV 参数化、环境场 B(x,v)、观察先验 V_prior
                              ↓
            ┌─────────────────────────────────┐
            │   Generator F(背景特征, 噪声)    │
            │   U-Net / SIREN / 扩散模型       │
            └─────────────┬───────────────────┘
                          ↓
               原始高分辨率纹理 T_raw
                          ↓
            ┌─────────────────────────────────┐
            │  物理约束前向传播                 │
            │  ┌───────────────────────────┐   │
            │  │ ① 下采样 → δ_min 像素    │   │
            │  │ ② 调色板量化 (STE)       │   │
            │  │ ③ 各向同性渲染投影        │   │
            │  └───────────────────────────┘   │
            └─────────────┬───────────────────┘
                          ↓
               最终纹理 T_constrained → 多视角渲染
                          ↓
                   与背景比较 → 损失反传
```

**关键工程决策**：

1. **漫反射纹理场 + 法向贴图**：不直接生成颜色，而是生成基础色 albedo + 法向扰动。这样光照由渲染器处理，纹理场只需学习材质属性，与光照解耦。
2. **分频段处理**：低频分量（大面积色块）用全局感知场；高频分量（纹理细节）用局部条件 GAN。两路输出融合为最终纹理。
3. **调色板量化**：使用直通估计器（STE）使量化操作可微。前向传播执行真正量化，反向传播跳过量化梯度。

#### 3.4.2 局部变形器生成

变形器优化是三维几何优化问题：

```
输入：目标网格 M、安装区域掩膜、环境场 B(x,v)
                              ↓
            ┌─────────────────────────────────┐
            │  变形器生成器                     │
            │  ┌ 形状 → 参数化基元库           │
            │  │   (阔叶/楔形/多边形/分叉形)   │
            │  ├ 位姿 → 注意力分布网络         │
            │  │   (高曲率/边缘区域权重高)     │
            │  └ 外观 → 与相邻纹理条件一致     │
            └─────────────┬───────────────────┘
                          ↓
               变形器集合 D = {d_1,...,d_K}
                          ↓
               附加到目标网格 → 联合渲染
                          ↓
                   与背景比较 → 损失反传
```

**轮廓打散度量**：定义边缘显著性损失：

$$\mathcal{L}_{\text{edge}} = \sum_{v \in \mathcal{V}_{\text{sample}}} \left\| \nabla_{\perp} \big( I_{\text{render}}(v) - I_{\text{background}}(v) \big) \right\|^2$$

即渲染图和背景图在垂直于目标轮廓方向上的梯度差。这迫使变形器生成的边缘与背景自然边缘的频率和方向一致。

### 3.5 Layer 4: 评估层——三层检测度量

#### 度量 M1: CV 特征损失（快速、可微、适配优化）

| 特征 | 度量 | 作用 |
|------|------|------|
| 颜色分布 | CIELAB 空间 EMD | 全局/局部颜色匹配 |
| 纹理频率 | Gabor 滤波器响应分布 | 空间频率一致性 |
| 结构相似性 | MS-SSIM | 多尺度结构匹配 |
| 边缘统计 | 梯度方向直方图 | 轮廓隐蔽性 |

综合：$\mathcal{L}_{\text{CV}} = w_1 \mathcal{L}_{\text{EMD}} + w_2 \mathcal{L}_{\text{Gabor}} + w_3 \mathcal{L}_{\text{MS-SSIM}} + w_4 \mathcal{L}_{\text{edge}}$

#### 度量 M2: 检测器损失（对抗性、语义级）

采用模型集成（ensemble attack）策略：

$$\mathcal{L}_{\text{model}} = \sum_{m \in \{ \text{YOLO, DINO, SAM}, \ldots \}} \alpha_m \cdot \text{detection\_score}_m(\mathcal{R}(\mathcal{T}, v))$$

- 实时检测器（YOLOv8/v10）：直接反向传播，提供可微攻击损失
- 基础分割模型（SAM）：黑盒评估边缘恢复质量
- VLM（Qwen2-VL / CLIP）：语义层面判断"是否像人造目标"

**关键策略**：检测器损失仅在优化后期引入（fine-tuning阶段），前期以 $\mathcal{L}_{\text{CV}}$ 和 $\mathcal{L}_{\text{human}}$ 为主，避免生成高频对抗噪点。

#### 度量 M3: 人眼代理模型（终极评价）

训练一个人眼视觉代理网络 $\mathcal{H}$，以人类实验数据为监督：

$$\mathcal{L}_{\text{human}} = \mathcal{H}\big( \mathcal{R}(\mathcal{T}, v) \big)$$

其中 $\mathcal{H}$ 输出预测的"检测时间"或"显著性分数"。

代理模型的训练数据来自 2AFC + 眼动追踪实验，目标是将 30+ 被试的检测行为编码为可微损失。

#### 三层关系

```
       时间尺度                抽象层次              成本
M1 ──── 每步迭代 ──── 像素/频率/边缘 ──── 自动、零成本
M2 ──── 每N步 ──── 语义/目标检测 ──── 中等（GPU推理）
M3 ──── 每轮实验 ──── 人类感知 ──── 高（实验设计+被试）

校准链：M1 粗筛 → M2 对抗微调 → M3 最终验证 → 权重更新
```

## 6. 与现有工作的定位

本方案的关键区分点（与 GANmouflage 等相比）：

| 维度 | GANmouflage (CVPR 2023) | 本方案 |
|------|------------------------|--------|
| 纹理表示 | 隐式纹理场 + NeRF | 显式 UV 纹理 + 物理约束前向传播 |
| 评估 | 单检测器 (Faster R-CNN) | 三层：CV特征 + 检测器集成 + 人眼代理 |
| 变形器 | 无 | 参数化变形器 + 轮廓打散 |
| 物理约束 | 无 | 像素尺寸 + 色域 + 各向同性 |
| 视角覆盖 | 固定稀疏采样 | 上半球连续空间 + 最坏视角优化 |

本方案的核心贡献可以定义为：

> **物理约束下的多视角联合纹理-几何伪装优化，满足可制造性约束并对齐人类视觉感知。**
